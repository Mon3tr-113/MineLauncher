方块启动器 MineLauncher v0.1.0  使用说明
========================================

一、怎么运行
  1. 把压缩包解压到任意位置（建议非系统盘的普通目录）。
  2. 双击 MineLauncher.exe 即可启动。
  3. **整个 MineLauncher 文件夹要一起保留**：exe 依赖同目录的 runtime\（精简 Java 运行时）
     和 app\（程序本体）。可以给 exe 建快捷方式，但不要把 exe 单独拷走。

二、不用装 Java
  启动器自带精简运行时，双击就能跑。
  游戏本体所需的 Java 由启动器负责：先自动识别本机已有的 Java，
  找不到合适的版本时会自动下载（Azul Zulu → 清华镜像 → Adoptium），
  下载位置在 %USERPROFILE%\.mclauncher\java\ 。

三、数据放在哪
  配置、账号、下载的版本、整合包实例、崩溃报告都在：
      %USERPROFILE%\.mclauncher\
  也就是说：删掉/替换程序文件夹不会丢配置；反过来，想彻底重置就删这个目录。

四、第一次用
  1. 「启动游戏」页默认已有一个离线账号 Steve，可以点「添加账号」换成微软正版或外置登录。
  2. 「下载资源 → 版本」搜索并安装要玩的版本（可选原版 / Fabric / Forge / NeoForge / Quilt）。
  3. 或者「下载资源 → 整合包」搜 Modrinth 整合包，**也可以直接把整合包文件拖进窗口**
     （支持 .mrpack、CurseForge 导出的 zip、带 mods/ 的普通 zip、已解压的实例目录）。
  4. 装好后回「启动游戏」选版本 →「启动游戏」。启动前会自动校验依赖库与资源文件，
     缺什么补什么（日志里能看到）。

五、常见提示
  - Windows 提示「无法验证发布者 / 已保护你的电脑」：这是未做代码签名的自打包 exe，
    点「更多信息 → 仍要运行」即可。若被杀毒软件误报，把整个文件夹加进信任列表。
  - 下载慢：设置里保持「使用国内镜像（BMCLAPI）」开启；下载中心会显示网速和剩余文件数，
    断开/卡住会自动重连续传。
  - 启动报 UnsatisfiedLinkError、ZipException、缺 mod：在「启动游戏」页点「校验依赖库」，
    或把整合包重新导入一次。
  - 需要联网：拉取版本清单（Mojang/镜像）、下载资源、Modrinth 搜索都需要网络。

六、卸载
  直接删掉程序文件夹即可；要连配置一起清掉，再删 %USERPROFILE%\.mclauncher。
